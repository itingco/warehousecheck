# WarehouseCheck V9.1 - Scan Errors View Hotfix

Hotfix ini memperbaiki error:

`InvalidArgumentException: View [admin.scan_errors] not found.`

## File yang ditambahkan

- `resources/views/admin/scan_errors.blade.php`

## Instalasi

Copy isi ZIP ke root project Laravel Anda, contoh:

`C:\xampp82\htdocs\Checker`

Lalu jalankan:

```powershell
php artisan optimize:clear
```

Tidak ada perubahan SQL atau migration.
